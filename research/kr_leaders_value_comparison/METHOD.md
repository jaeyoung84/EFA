# 대장주·저평가주 기존 산출물 검증 및 완전 명단 재집계

<!-- Codex 수정: CODX-KRLC-001 (2026-10-16), 파일 전체. -->

사용자 요청: 대장주만 백테스트하고 완료된 저평가주 결과를 찾아 비교한다.

- 기존 저평가 결과: `research/external_picks_kr/out/monthly_performance.csv`, `stock_month_returns.csv`.
- 조사 중 대장주를 이미 계산한 `out/compare_stock_months.csv`, `compare_monthly.csv`, `compare_groups.csv`도 발견했다. 이를 재사용한다. 본 문서는 결과 열람 뒤 작성한 작업 기록이며 사전등록이 아니다.
- 원본 PDF 두 개의 페이지별 월/종목코드를 독립 추출하여 기존 산출물 구성과 대조한다. 2024-10~2026-09 완결 24개월만 비교한다. 2026-10은 서로 수집시각이 달라 제외한다.
- 기존 계산 방식: 매월 첫 거래일 시가 매수, 마지막 거래일 종가 매도, 매월 동일 비중으로 재설정, 월별 수익 복리 연결. 월말 종가~다음 월초 시가 수익은 제외한다. Yahoo auto_adjust=True 가격을 이용한 분할·배당 조정 수익의 근사이며 실제 배당 현금흐름 원장 재현은 아니다. 비용·세금 제외.
- 대장주 기존 산출물에서 2026-02의 012510 더존비즈온이 누락되었다. 19종목 평균을 그대로 20종목 결과로 보고하지 않는다. 기존 로컬 KRX 스냅샷을 읽기 전용으로 조회해 월초 시가·월말 종가를 보충한다. 월중 상장주식 수 변화·거래정지 여부를 점검한다. 이 한 건은 현금배당 조정을 확인하지 못한 가격수익률이며 출처 차이를 별도 명시한다. 보완 전 결과도 보존한다.
- 저평가 월별 성과와 개별 종목 평균의 일치를 검증하고 그대로 사용한다. 새로운 저평가 백테스트·전체 운영 파이프라인·연구 스윕·holdout 개방은 실행하지 않는다.
- 지표: 누적수익, 24개월을 2년으로 환산한 CAGR, 월수익 연환산 변동성, 최초 원금 포함 월말 최대낙폭, 양수 월수, 상대 우위 월수, 달력연도별 부분기간 수익. 월말 낙폭은 일별/장중 최대낙폭이 아니다.
- 기존 두 PDF의 월 제목·실제 공개시각이 확인되지 않아 소급 탐색 비교다. 시점정합·독립 성과 검증 또는 운영 채택 근거로 쓰지 않는다. 두 목록 교집합 등 추가 전략은 평가하지 않는다.
- 변경 범위: 이 폴더의 검증·재집계 실행기와 문서/결과, docs/CODEX_CHANGES.md의 해당 ID 행, docs/engine/CHANGES.md의 해당 ID 절. 기존 사용자 작업·엔진·DCA·잠긴 KR-LV-v2 규칙은 수정하지 않는다.
- 회귀 검증 필요: 원금 포함 낙폭, 복리 산술, 누락 종목 차단, PDF 500/375개 기록과 24개월 전수 대조. 새 전략 성과 테스트가 아닌 재집계 정확성 검증이다.
