# 대장주 가치주와 저평가 가치주 비교

<!-- Codex 수정: CODX-KRLC-001 (2026-10-16), 파일 전체. -->

대장주 명단의 누적수익은 **+129.43%**, 기존 저평가 명단은 **+97.22%**다.
2024년 10월~2026년 9월의 완결 24개월을 같은 월별 방식으로 연결한 소급 계산이다.
기존 대장주 산출물도 발견하여 개별 종목 기록을 재사용했고, 누락 1건을 보완했다.
새로운 저평가주 백테스트나 기존 전략 러너는 실행하지 않았다.

대장주의 누적 우위는 **32.21%p**다. 월수익에서 저평가주를 이긴 달은 13/24개월로,
매달 일관되게 앞선 것은 아니다. 월평균 차이는 +0.62%p, 단순 대응표본 t값은 약 0.70이다.
독립성·정규성 등을 검증한 유의성 판정이 아닌 설명 통계다.
2026년 2월(+18.39% 대 +5.91%)과 3월(-6.29% 대 -15.29%)의 차이가 컸다.
반대로 2026년 5월에는 대장주 -0.17%, 저평가주 +7.70%였다.

두 명단 모두 이 방식의 KODEX 200 수익보다 낮고 동일가중 ETF보다 높다.
재무지표만 보고 저평가주가 더 나은 전략이라고 단정할 수 없으며,
이 표본에서는 대장주가 누적수익과 월말 낙폭에서 더 나았다.
이는 기존 KR-LV-v2의 잠긴 규칙을 변경하거나 대장주·교집합 전략을 새로 채택할 근거가 아니다.

## 계산 조건과 한계

- 매월 첫 거래일 시가 매수 → 같은 달 마지막 거래일 종가 매도, 종목별 동일 비중, 매월 재설정.
  월말 종가에서 다음 달 첫 시가까지의 수익은 제외한다. 따라서 계속 보유한 실제 계좌/ETF의 총수익과 다르다.
- 비용·세금·슬리피지 미반영. 기존 Yahoo `auto_adjust=True` 산출물을 재사용한 근사치다.
- 2026년 10월은 진행 중이고 두 산출물의 수집시각도 달라 비교에서 제외했다.
- PDF 월 표기와 당시 공개 시각, 과거 명단의 시점정합성을 확인하지 못했다. 소급 탐색 결과이며 독립 성과 입증이 아니다.
- 최대낙폭은 최초 원금과 월말 수익곡선으로 계산했다. 월중·장중 하락을 포함하지 않으므로 일별 최대낙폭으로 읽지 않는다.

## 누락 보완과 검증

- PDF 두 개에서 월별 코드를 독립 추출: 대장주 25개월×20개=500개 기록, 저평가주 25개월×15개=375개 기록.
- 완결 24개월의 대장주 저장 기록은 479/480건이었다. 2026년 2월 더존비즈온(012510)이 없어 기존 산출물은 19종목 평균이었다.
- 기존 KRX 스냅샷을 `mode=ro`로 조회: 2026-02-02 시가 94,500원 → 2026-02-27 종가 118,400원,
  가격수익률 +25.2910%. 해당 월 17거래일 전부 존재하고 상장주식 수 일정, 가격·거래량 양수임을 확인했다.
- 해당 1건의 현금배당 조정 여부는 확인하지 못했다. 다른 479건의 Yahoo 조정 수익과 출처·처리가 완전히 같지는 않다.
  보완 전 대장주 누적은 +128.73%, 보완 후 +129.43%다. 이 차이로 두 목록의 누적 순서는 바뀌지 않는다.
- 보완 후 대장주 480/480건, 저평가주 기존 360/360건 명단 일치. 저평가주 기존 월별 결과와 개별 수익 평균을 전수 대조했다.
- 원본 PDF·기존 CSV를 수정하지 않았다. 파일 SHA-256, 보완 KRX 조회행 해시, 코드·방법·설정 해시,
  비용 가정·기준 기간·실행 환경을 RESULT.json에 각각 기록했다.
- 산술·원금 포함 낙폭·누락 차단 회귀 테스트 3개 통과. 엔진 근거 무결성 검사 통과.
