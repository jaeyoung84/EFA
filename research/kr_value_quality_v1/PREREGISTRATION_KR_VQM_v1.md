작성 2026-10-14, Claude Code. 사용자 지시("우리 저평가 가치주를 어떤 방향으로 찾을지", "진행해보자").
**2026-10-14 사용자 확인("잠그고 실행해") 후 잠금.** 데이터 품질 점검(수익률·성과 미열람, §7)을 마친 뒤 SHA-256으로 잠갔다.

## 0. 출처와 열람 공개

- 착안: InvestingPro '한국 저평가 가치 투자주' 25개월 분석(research/external_picks_kr). 그 명단은 시총·유동성·흑자·저평가
  조건으로 거른 대형 가치주였고, 200 동일가중 대비 월 +0.93%p(t=0.86, 유의하지 않음), 하락장 방어, 명단 안 지표의 예측력 없음.
  전달 명단에 남은 종목이 신규 편입보다 나았다(+1.65%p vs −0.12%p)는 사후 관찰을 보고 '가치 함정 방지(모멘텀)' 장치를 넣었다.
  이 관찰은 같은 자료에서 나온 것이므로 근거가 아니라 착안이다.
- 작성자는 한국 개별주의 가치·퀄리티 지표와 수익률의 관계를 이 데이터(KRX 일봉 2016-08~, DART 주요계정)로 본 적이 없다.
  한국 엔진의 기존 연구(평균회귀·Pullback)는 가격 신호만 썼고 재무 지표를 쓰지 않았다.
- 같은 KRX 기간을 다른 가설군(평균회귀, Pullback T-0·v1~v4)이 이미 사용했다. 이 가설은 재무 기반의 별개 군이며, 이 군의 첫 선언 관측이다.

## 1. 데이터

- 가격·시총: 서버 KRX 일봉 DB 스냅샷(상장폐지 포함, 2016-08-29~). 수정주가가 아니므로 액면분할·병합은
  상장주식수 변화와 가격 변화가 함께 일어난 날을 찾아 조정한다(§1.1). **배당은 반영하지 않는다**(가치주에 불리한 쪽).
- 재무: DART 다중회사 주요계정(연결 우선, 없으면 별도). 매출액, 영업이익, 당기순이익, 자산·부채·자본총계.
  분기 손익은 보고서별 3개월 값, 4분기 = 연간 − 1~3분기. TTM = 최근 4개 분기 합.
  - 계정명 변형: '영업이익(손실)' → 영업이익, '당기순이익(손실)' → 당기순이익(2차 수집의 전 계정 목록 32개에서 확인).
  - 빈 손익 보충: 주요계정 API가 일부 회사의 손익 줄을 빼고 준다(예: 매출 대신 '영업수익', 연결 순이익 줄 누락).
    유니버스 후보(형성 기간 중 월말 시총 ≥ 5,000억, 금융업 양식 제외)에서 빈 항목만 단일회사 전체 재무제표 API로
    채운다(같은 연결·별도 구분, 손익계산서 우선, 표준 계정 ID 우선 뒤 계정명 일치 — 공백·번호 머리('VIII.')·'연결'·'(손실)'을 지운 뒤 비교).
    원래 값은 덮어쓰지 않는다. '영업손실'·'당기순손실'처럼 이익을 뜻하는 말 없이 '손실'로 끝나는 줄은 부호가 모호해 쓰지 않는다.
  - 4분기 매출이 음수로 계산되면(누적값 보고 등) 그해 4분기 손익을 쓰지 않는다.
  - 2015년 1~3분기 자료는 API에 없다(전 법인). 그래서 2015년 4분기를 만들 수 없고, 초기 몇 달은 ROE 개선 값이 비는 종목이 있다(§3).
- **시점 규칙(미래 정보 차단)**: 분기·반기 보고서는 분기 말 + 45일, 사업보고서는 사업연도 말 + 90일이 지나야 사용한다.
  DART API는 정정 후 최신 값을 주므로 정정 전 원본을 재현하지 못한다(한계, §6).
- 상장폐지 법인은 종목코드가 없어 회사명 정확 일치로만 연결한다(실제 0건 — corpCode.xml이 상장폐지 법인의 종목코드도 유지).
- 연결 비율(판정용) = 유니버스(§2의 시총·유동성·금융업 조건 적용 후) 시총 중, 형성일까지 공개된 최근 1년 안 분기 자료가 있는 법인의 비중.
  최종 적격 비율(보고용) = 그중 TTM·자본 조건까지 통과한 비중. 둘 다 매월 기록한다.

### 1.1 분할 조정
전일 대비 상장주식수 비율 r(≥1.5 또는 ≤0.67)이 있고 같은 날 종가 비율이 1/r의 ±25% 안이면 그 이전 가격을 r로 나눠 조정한다.

## 2. 유니버스 (매월 형성일 기준)

- 코스피·코스닥 보통주(종목코드 끝자리 0, 이름에 '스팩'·'리츠' 없음, ETF·ETN 제외, 형성일 구분이 관리종목·SPAC이면 제외).
- 형성일 시가총액 ≥ 5,000억원, 최근 20거래일 평균 거래대금 ≥ 20억원, 최근 12개월 일봉 ≥ 200일.
- TTM 매출·영업이익·순이익(연속 4개 분기, 첫 분기 말~마지막 분기 말 250~300일)과 최근 자본총계가 있고, 자본총계 > 0, TTM 매출 > 0.
- **금융업 양식 법인 제외(전 기간)**: 주요계정 API에 2023년 전 자료가 없고 순이자손익·순수수료손익·보험계약부채·예수부채 중
  하나가 있는 법인(은행·보험·금융지주 등, 69개). 이 API가 금융업 양식을 2023년 3분기부터만 주므로 기간 내내 같은 기준을 쓰려고 뺀다.
  일반 양식으로 보고하는 증권·카드사 등은 남는다. 부채비율 지표는 쓰지 않는다.
- 형성일 최근 1년 자료에 매출액이 전혀 없는 법인은 제외(보충 후에도 매출이 없는 지주·바이오 등).

## 3. 신호와 포트폴리오

형성일 = 매월 마지막 거래일 종가. 매매 = 다음 달 첫 거래일 시가. 유니버스 안 백분위 순위(0~1, 높을수록 좋음).

- 가치 V = 평균(E/P, B/P, S/P) — E/P = TTM 순이익 / 시총, B/P = 자본총계 / 시총, S/P = TTM 매출 / 시총.
- 퀄리티 Q = 평균(ROE, 영업이익률, ROE 개선) — ROE = TTM 순이익 / 자본총계, 영업이익률 = TTM 영업이익 / TTM 매출,
  ROE 개선 = 지금 ROE − 4분기 전 ROE.
- 가치 함정 방지 M = 12-1개월 수익률(형성일 기준 12개월 전 종가 → 1개월 전 종가). **M 하위 30%는 제외.**
- 종합 = 0.5 V + 0.5 Q. 남은 종목 중 상위 20개, 동일 비중. 순이익 ≤ 0인 종목은 E/P 최하위.
  4분기 전 ROE를 계산할 수 없는 종목(상장 1년 안팎, 2015년 자료 공백)은 ROE 개선 순위 최하위. 모멘텀 자료가 없으면 M 최하위(→ 제외 대상).
- 비용(편도): 매수 6.5bp, 매도 24.5bp(한국 엔진 D-43과 같은 2026 세율 기준). 교체 비중만큼 차감.

## 4. 기간·판정

- 형성 2017-09 ~ 2026-08(보유 2017-10 ~ 2026-09), 약 108개월. **한 번만 실행**한다.
- 주 비교 대상: 같은 유니버스 동일 비중(매월 같은 날 같은 방식). 보조: KODEX 200, 유니버스 시총 가중.
- **PASS**: 월 초과수익(주 비교 대상 대비, 비용 차감) 평균 > 0 이고 t ≥ 2.0, 그리고 블록 부트스트랩(12개월 블록, 10,000회,
  seed 20261014) 평균 초과 95% 하한 > 0, 그리고 달력 연도 9개 중 6개 이상 초과 양수.
- **FAIL**: 평균 > 0이지만 위 중 하나라도 미달 → 힌트, 전향 관측만 가능(사용자 결정).
- **REJECT**: 평균 ≤ 0 → 종료.
- **INVALID**: 연결 비율(§1) 80% 미만인 달이 12개월 넘게 있음, 분할 조정 실패로 월 수익률 ±80% 초과가 남음.

## 7. 잠금 전 데이터 점검 기록(수익률·성과 미열람)

- 1차 수집(주요 8개 계정만 저장)은 최종 적격 시총 비율 최저 76%, 80% 미만 23개월. 원인: '영업이익(손실)' 계정명, 묶음 단위 '자료 없음' 응답.
- 2차 수집(전 계정 저장, 빈 묶음을 10개 단위로 재조회) + 계정명 변형 처리: 연결 비율 최저 88%, 최종 적격 최저 77%(80% 미만 14개월).
  남은 원인: 은행·보험·금융지주(2023년 전 자료 없음), 일부 회사의 손익 줄 누락(현대차 연결 순이익, 카카오 '영업수익' 등).
- 금융업 양식 제외 + 빈 손익 보충(1,109개 보고서, 973개 항목 채움) 뒤 `run.py --check`: 108개월, 유니버스 190~(중앙값 299.5),
  연결 비율 최저 99.0%(80% 미만 0개월), 최종 적격 비율 최저 93.0%·중앙값 97.8%, 분할 조정 739건.
- 대표 회사 TTM 값 대조(삼성전자·현대차·카카오·SK하이닉스·LG화학, 2018-06/2021-06/2024-06): 공시 값과 일치.
- 잠금 전 코드 수정: 빈 값 순위 방향 오류(pandas `na_option="bottom"`이 빈 값을 최고 순위로 줌 → "top"으로 고쳐 최하위),
  20거래일 평균이 19일만 쓰던 오류, INVALID 자동 판정과 ±80% 보유 종목 기록 추가. 3개월 구간 실행 경로 시험은 출력을 보지 않고 형식만 확인.
- 이 과정에서 본 것은 유니버스 크기·연결 비율·개별 회사 재무 값뿐이며, 어떤 종목·포트폴리오의 수익률도 계산하거나 보지 않았다.
