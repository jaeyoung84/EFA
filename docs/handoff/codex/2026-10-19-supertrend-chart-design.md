# 슈퍼트렌드 독립 차트 — Claude Code 구현용 설계

<!-- Codex 수정: CODX-ST-DESIGN-001 (2026-10-19), 이 문서 전체. -->

- 사용자 목적: 본인이 종목 차트를 보며 매수·보유·매도 판단에 참고한다. 구현은 Claude Code 담당.
- 범위: 별도 기술 차트 화면의 설계. 엔진 추천·기존 청산·전향 관측·자동매매에 연결하지 않는다.
- 상태: 설계만 작성. 아래 조합의 수익 개선·승률·최적 파라미터는 검증하지 않았다.
- 첨부 Pine 원본은 일봉 Supertrend(ATR 10, 배수 3), 직전 확정 주봉 방향, 일봉 확정 전환을 표시한다.
- 이 문서를 읽고 새 코드로 구현하는 것은 문서 수정이 아니다. 이 문서 및 다른 Codex 표시 구역 자체를 변경하는 경우 협업 변경 잠금을 따른다.

## 1. 핵심 제품 결정

차트는 다음 네 질문에 각각 답한다.

| 질문 | 주 표시 |
| --- | --- |
| 지금 어떤 추세인가? | 일봉 Supertrend 방향·지속 거래일·직전 확정 주봉 방향 |
| 전환이 이어질 환경인가? | ADX14, 거래량 배율, 최근 전환 빈도, 시장지수 방향 |
| 지금 가격에 진입하면 거리가 얼마나 되는가? | 추세선 거리 %, ATR 단위 거리, 직전 고점·저점 |
| 보유 중 무엇이 달라졌는가? | 모든 하락 전환, 전일 확정 추세선, 마지막 신호 이후 가격 변화 |

신호 강도를 임의의 합산 점수나 매수 확률로 바꾸지 않는다. 서로 비슷한 가격 지표가 여러 개 맞아도 독립된 증거가 여러 개 생기는 것은 아니다.

## 2. 원본에서 반드시 보완할 동작

| 원본/구현 위험 | 설계 결정 |
| --- | --- |
| 주봉 상승일 때 일봉 SELL도 필터링됨 | 원본 일봉 상승·하락 전환을 모두 보존. 주봉 방향 일치는 라벨의 테두리·설명으로 구별. 특히 하락 전환은 항상 표시 |
| 일봉 상승 전환은 주봉 하락 중 반등일 수도 있음 | 일봉·주봉 4조합을 따로 표시. 주봉 하락 속 상승을 `역추세 반등`으로 설명 |
| `현재 봉 신호 없음`이 마지막 신호를 지워 보이게 함 | `현재 추세`, `오늘 전환`, `최근 확정 전환 날짜/가격`, `전환 후 거래일 수`를 각각 유지 |
| 장중 값이 확정 신호처럼 보임 | 확정 봉만 신호 생성. 장중 봉을 제공한다면 점선/반투명과 `미확정` 표시. 장중 봉이 없으면 마지막 수집 일자와 종가를 표시 |
| 추세선이 전환일에 반대쪽으로 이동 | 활성 ST선과 `전일 확정 상승 ST선`을 구분. 새 하락 ST선을 기존 상승 지지선처럼 설명하지 않음 |
| BUY/SELL을 체결 사실로 오해 | `BUY·상승 전환`, `SELL·하락 전환`으로 설명. 신호 시점은 종가 확정 후이며 같은 종가 체결을 가정하지 않음 |
| 횡보에서 잦은 전환 | ADX와 직전 20거래일 전환 횟수를 표시. 원 신호를 지우지는 않음 |

| 영역 | 기본 표시 | 선택 표시 |
| --- | --- | --- |

| 상태 줄 | 일봉 방향, 확정 주봉 방향·기준 주, 최근 전환일·지속 거래일 | 비교 지수 방향 |
| 주 차트 | 실제 OHLC 캔들, 초록/빨강 ST선, 모든 전환 마커, 십자선·확대·이동 | SMA20/60/200, 직전 20·60일 고점/저점, 수동 수평선 |
| 거래량 패널 | 거래량 막대, 직전 20일 평균 대비 배율 | 거래대금 |
| 추세 강도 패널 | ADX14와 20·25 기준선 | +DI/-DI, RSI14 또는 OBV 중 선택한 보조 패널 |
| 판단 카드 | 추세선 거리 %, ATR 단위 거리, 마지막 확정 가격/시각, 전환 횟수 | 사용자 입력 진입가·수량으로 금액 거리 계산 |

기본 화면에 RSI·MACD·OBV·여러 이동평균을 모두 겹치지 않는다. 이동평균은 위치를 읽는 선택 도구이며 기존 RSI-OBV 엔진의 진입 필터가 아니다.
모바일에서는 가격·거래량을 우선 배치하고 나머지 패널을 접는다. 상승/하락은 색상과 글자·화살표를 함께 사용한다.

## 4. 추세 해석 문구

| 직전 확정 주봉 | 확정 일봉 | 차트 설명 | 사용자가 확인할 내용 |
| --- | --- | --- | --- |
| 상승 | 상승 | 중기·단기 상승 방향 일치 | 진입 시점의 거리·직전 고점·거래량 |
| 상승 | 하락 | 중기 상승 속 단기 약화 | 눌림인지 추가 하락인지, 하락 전환일·추세선 이탈 |
| 하락 | 상승 | 중기 하락 속 단기 반등 | 반등 지속·직전 고점 회복 여부, 추격 거리 |
| 하락 | 하락 | 중기·단기 하락 방향 일치 | 하락 추세 유지 여부, 아직 없는 상승 전환을 미리 확정하지 않기 |

위 설명은 조건에 따른 사실 요약이며 매수 추천·매도 지시 또는 성공 확률이 아니다.
주봉은 후행하므로 불일치를 모두 나쁜 신호로 취급하지 않는다. 추세 초입과 약한 반등을 구분하는 보조 맥락이다.

## 5. 수치 정의와 해석

계산은 선택한 과거 봉 t를 기준으로 한다. C=종가, H/L=고가/저가, ST=활성 슈퍼트렌드, ATR10=슈퍼트렌드와 동일 ATR.

| 항목 | 정확한 정의 | 표시 원칙 |
| --- | --- | --- |
| 추세선 거리 | 상승 중 `(C-ST)/C*100`, 하락 중 `(ST-C)/C*100` | `하락 여유` 같은 보장 표현 대신 `추세선까지 거리` 사용 |
| ATR 단위 거리 | `abs(C-ST)/ATR10` | 원화가 다른 종목의 거리 비교에 도움. 커졌다고 고평가 또는 하락 확정은 아님 |
| ATR% | `ATR10/C*100` | 최근 변동성 수준. 방향 지표가 아님 |
| 거래량 배율 | `V[t]/mean(V[t-20:t-1])` | 오늘을 평균에서 제외. 장중 누적량은 확정 일봉 평균과 동일 조건으로 비교하지 않음 |
| ADX14 | Wilder 방식, DI 기간14·ADX 평활14 | `<20 약한 추세`, `20~25 중간`, `>25 강한 추세`는 관행적 눈금. 상승/하락 방향은 ST를 따로 확인 |
| 전환 빈도 | t까지 최근 20개 확정 거래일의 방향 전환 횟수 | 원숫자 표시. `3회 이상=주의` 등을 쓰면 검증되지 않은 UI 기준이라고 명시 |
| 직전 고점/저점 | t 이전 20/60개 거래일 H의 최댓값/L의 최솟값 | 오늘 제외. 고점은 잠재 저항 참고이며 목표가로 단정하지 않음. 돌파하면 `직전 고점 돌파`로 표시 |
| 전환 후 변화 | `(C[t]/전환일 확정 종가-1)*100` | `신호 후 가격 변화` 표기. 매매 수익률·성과로 표시하지 않음 |
| 시가 갭 | `(O[t]/C[t-1]-1)*100`, 선택적으로 `abs(O[t]-C[t-1])/ATR10[t-1]` | 원숫자 표시. ATR 비교는 당일 변동으로 부풀지 않게 전일 ATR 사용 |

거리 1ATR·2ATR, 거래량 1.5배 등은 이해를 돕는 눈금으로만 제공한다. `2ATR 이상 매수 금지`, `1.5배 이상 승률 우수`는 근거가 없으므로 기본 규칙으로 만들지 않는다.
거래량이 없거나 경제적 의미가 다른 지수/상품은 0배 대신 `제공 안 됨`으로 처리한다.

## 6. 실제 읽는 순서

1. 매수 검토: 확정 상승 전환과 주봉 방향을 확인 → ADX·거래량·최근 전환 횟수를 확인 → ST 거리·직전 고점을 보고 현재 가격에 감수할 거리를 판단.
2. 보유 검토: 일봉 상승 지속과 ST선 변화를 확인 → 일봉 약화/하락 전환이 생겼는지 확인 → 주봉과 무관하게 하락 전환을 볼 수 있어야 함.
3. 매도 검토: 종가 확정 하락 전환을 우선 확인. 장중 전일 ST 이탈은 `장중 이탈`로 따로 표시. 두 사건의 날짜와 의미를 섞지 않음.
4. 재진입 검토: 다시 확정 상승 전환이 생기면 새로운 전환으로 기록. 직전 실패 전환을 삭제하거나 새 전환으로 덮어쓰지 않음.

사용자 입력 진입가가 있는 경우 상승 ST선이 진입가 위에 있는지 보여 줄 수 있다. 해당 선의 이익이 보장된다는 뜻은 아니다.
계획 가격 P와 사용자가 고른 무효화 기준 S, 수량 Q를 입력하면 `(P-S)*Q`의 가격 차이 금액을 표시할 수 있다.
수수료·갭·슬리피지가 반영되지 않은 단순 계산임을 명시한다. 입력은 차트용이며 기존 원장에 자동 저장/연결하지 않는다.
R배수는 사용자가 유효한 S<P<T를 직접 정한 경우만 `(T-P)/(P-S)`를 제공한다. 직전 고점을 자동 목표가로 지정하지 않는다.

## 7. 미래 정보를 섞지 않는 계산과 데이터

- TradingView 공식 Supertrend의 hl2·TR·RMA·상하단 밴드 재귀식·초기 방향·동률 처리까지 맞춘다. ATR은 매번 rolling SMA로 재계산하지 않는다.
- 일봉과 주봉은 각각 원 OHLC에서 독립 계산한다. 일봉 ST를 주 단위로 샘플링해서 주봉 ST를 만들지 않는다.
- 주봉은 거래소 현지 주간·정규장 달력으로 묶고, 첨부 `[1]+lookahead_on`처럼 해당 일봉에 사용 가능했던 직전 주 값만 매핑한다. 현재 최신 주봉 값을 과거 전환 모두에 적용하지 않는다.
- 금요일 장 마감 직후 확인 가능한 이번 주 완료 주봉을 추가 제공하려면 `이번 주 마감값`과 원본의 `직전 주 참조값`을 별도 명시한다. 조용히 매핑 의미를 바꾸지 않는다.
- 휴장·조기 마감·서머타임은 시장 달력으로 확정한다. 날짜가 바뀌었다는 이유만으로 일봉을 확정하지 않는다. 공급자 일봉 수집 완료도 확인한다.
- 한국 KRX/NXT·미국 정규장/시간외 혼합 여부를 표기한다. 가격·거래량·주봉이 같은 세션 범위여야 한다.
- 분할 등 기업행동 조정 방식을 OHLC 전체에 일관 적용하고 출처·통화·조정 여부·최근 수집 시각을 표시한다. 조정 과거 가격과 실제 매입가를 단순 혼용하지 않는다.
- 계산 이력은 표시 구간보다 길게 유지한다. 초기 권장 3~5년을 확보하고 상장 이력이 짧으면 가능한 이력만 사용하며 계산 안정성을 별도 확인한다. `10봉 충족=완전히 안정`으로 간주하지 않는다.
- 6개월/1년 표시 버튼을 바꿔도 동일 날짜의 ST·신호가 달라지면 안 된다. 기준 계산 이력과 시드를 고정하고 계산 결과를 잘라 표시한다.
- ST는 누적 계산이므로 새 데이터를 뒤에 추가했을 때 기존 확정 값이 바뀌는지 확인한다. 공급자 정정/분할 재조정이 있으면 수정 이유·버전을 보존한다.
- 누락 봉·거래정지·불량 OHLC를 정상 캔들로 채우지 않는다. 관련 전환은 자료 확인이 끝날 때까지 미확정 처리한다.
- 과거 봉을 선택하면 당시 ADX·RVOL·주봉·거리·설정이 모두 동기화된다. 최신 수치를 과거 신호 설명에 섞지 않는다.
- 전환 후 5일 이내 반대 전환 같은 사후 실패 분석을 제공한다면, 최초 신호와 사후 판정 날짜를 분리한다. 미래 결과로 과거 신호를 지우지 않는다.

## 8. Claude Code 구현 순서와 완료 기준

| 우선순위 | 구현 범위 | 완료 기준 |
| --- | --- | --- |
| 1 | 독립 일봉 차트·원 ST·확정 주봉·모든 전환·설정·데이터 표시 | 첨부 규칙 재현, SELL 누락 없음, 확정/진행 중 구분 |
| 2 | 거래량 배율·ADX·ST 거리·전환 횟수·과거 봉 상태표 | 각 값이 선택 봉과 일치, 결측을 0으로 오인하지 않음 |
| 3 | 선택 MA·직전 고저·벤치마크 상태·수동 가격/거리 계산 | 원 신호 유지, 사용자 입력 원장 미접속 |

필수 검증은 추세 반전/동률/초기값 합성 데이터, 주중·금요일·휴장 주봉 정렬, 주봉 상승 중 SELL, 캐시 지연·누락·분할, 이력 추가/표시 구간 변경 불변성, 모바일·확대·도구 해제다.
TradingView와 대조할 때 동일 거래소·세션·조정·설정·입력 OHLC를 먼저 맞춘다. 다른 공급자 결과의 불일치를 무조건 계산 버그로 단정하지 않는다.
최소 상승/하락/횡보·짧은 상장 이력·휴장 주·분할 사례를 포함해 값과 전환 날짜를 대조하고 오차를 남긴다. 이 문서 작성 시 Pine 컴파일·차트 대조·성과 백테스트는 실행하지 않았다.

초기 범위는 화면이다. 알림·성과표·스캐너·수익률 최적화는 후속 범위로 남긴다. 차트가 일치한다는 사실과 수익성이 검증됐다는 사실을 구분한다.

## 9. 근거와 설계 판단의 구분

- [TradingView Supertrend 공식 계산](https://www.tradingview.com/support/solutions/43000634738-supertrend/): 추세추종·ATR 기반, 밴드 재귀식, 거짓 전환 가능성.
- [TradingView ATR 공식 설명](https://www.tradingview.com/support/solutions/43000501823-average-true-range-atr/): TR과 기본 RMA. ATR은 변동성 지표.
- [TradingView 상위 시간대 확정값](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/): 과거 오프셋과 lookahead 조합으로 확정 HTF값 매핑.
- [Fidelity ADX](https://www.fidelity.com/viewpoints/active-investor/average-directional-index-adx): 방향과 구분되는 추세 강도 및 20/25 관행적 기준.
- [Fidelity 기술분석 설명](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/what-is-technical-analysis): 거래량·지지/저항의 보조 맥락.
- [SEC/Investor.gov 스톱 주문 설명](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-15): 기준 가격과 실제 체결 가격의 차이.

위 근거는 각 지표의 의미를 뒷받침한다. 이 설계의 조합, 화면 눈금, 매수·매도 유용성 또는 수익 개선을 검증한 근거는 아니다. 조합과 UX 우선순위는 Codex의 설계 제안이다.
