# InvestingPro 두 한국 명단의 월별 비교와 공통 종목 전향 검증

## 목표 — 사용자에게 무엇이 달라지는지 1~3문장

매달 InvestingPro의 **‘한국 저평가 가치 투자주’와 ‘한국 대장주 가치 투자주’**를 함께 기록하고, 공통 종목·각 명단에만 있는 종목·연속 편입 여부와 이후 성과를 비교한다. 우선 **두 명단의 공통 종목 전체를 하나의 선정 규칙으로 사전등록**해, 앞으로 원래 두 명단보다 나은지 검증한다. 검증 중에는 사용자 검토 후보로 제공하며, KQS 운영 추천이나 자동매매에는 적용하지 않는다.

## 결정 사항 — 선택한 방식과 이유, 버린 대안

### 1. 비교 대상과 기존 연구의 관계

| 구분 | 결정 |
|---|---|
| V | InvestingPro ‘한국 저평가 가치 투자주’ |
| L | InvestingPro ‘한국 대장주 가치 투자주’. 사용자가 확정했으므로 의미에 관한 추가 질문 없음 |
| 새 선정 후보 S | 해당 월의 **V∩L 전체** |
| KR-LV-v2 | 별도의 잠긴 연구로 유지. 명단을 확보한 달에 참고 비교만 하고, 선정 규칙·판정·전향 표본을 합치지 않음 |
| 버린 해석 | ‘한국 대장주’를 코스피 시총 상위 종목이나 우리 KR-LV-v2로 해석하지 않음 |

**공통 종목을 선택하는 이유는 두 명단을 비교하는 가장 단순하고 설명 가능한 규칙이기 때문이다.** 과거 누적수익률이 가장 높아서 선택한 것으로 정당화하지 않는다. 같은 공급자의 두 명단이므로 공통 편입을 독립적인 두 기관의 검증으로 설명해서도 안 된다.

### 2. 기존 25개월은 착안·자료 점검에만 사용

확인한 `out/compare_groups.csv`의 완결 24개월 결과는 다음과 같다.

| 구분 | 누적수익률 | 200동일가중 대비 월평균 | 해석 |
|---|---:|---:|---|
| V | +97.2% | +0.93%p | 우월성 미확인 |
| L | +128.7% | +1.53%p | 추가 관찰의 착안 |
| V∩L | +206.5% | +3.03%p | 연환산 변동성 36.4%, 월 구성 2~13종목으로 집중 위험 |
| L 연속 편입 | +176.1% | +2.46%p | 23개월, 사후에 본 여러 그룹 중 하나 |
| KODEX200 / 200동일가중 | +249.0% / +57.0% | — | 시총가중 시장 대비 성과도 함께 확인해야 함 |

- 이 결과는 **소급 입력·비용 미반영·10개 그룹 탐색 결과**다. 개별 t값을 확증적 유의성이나 채택 근거로 사용하지 않는다.
- 2024-10~2026-10 명단과 이미 열람한 결과는 탐색 자료로 등록한다. 2026-10은 진행 중인 달이며 새 전향 표본으로 편입하지 않는다.
- 허용: 기존 결과 인용, 원문 대조, 해석 오류·중복·누락 점검, 합성 데이터 회귀 검증.
- 금지: 같은 기간에서 종목 수·PER·ROE·금융 비중·연속 편입 조건을 바꾸며 우승 규칙 재선정. 나중에 기간을 나눠 ‘미사용 holdout’으로 부르는 것도 금지한다.
- 과거 비교는 Yahoo 조정가격의 **월 첫 시가→월 마지막 종가**다. 새 전향 평가와 별도 계열로 표시하고 누적선을 연결하지 않는다.
- KR-VQM-v1의 REJECT와 KR-LV-v2의 잠금을 유지한다. 조사 시 KR-LV-v2 문서·실행기 해시는 `LOCK.json`과 일치했다.

### 3. 매달 누적할 자료와 비공개 보관

**명단 원문과 원문을 복원할 수 있는 종목별 파생자료는 Git에 넣지 않는다.** 사이트에서도 로그인한 본인에게만 제공한다.

| 자료 | 저장 위치·형식 | 필수 내용 |
|---|---|---|
| 원문 | `research/external_picks_kr/private/raw/<V또는L>/<YYYY-MM>/<capture_id>/original.<pdf또는csv또는txt>` | 사용자가 직접 확보한 파일 그대로, SHA-256 |
| 정규화 명단 | `research/external_picks_kr/private/normalized/<V또는L>/<YYYY-MM>/<capture_id>.json` | 원문 종목코드, 표준 식별자·시장, 이름, 원문 순서, 지표·단위·결측, 원문 페이지·행 연결 |
| 시점·정정 이력 | `research/external_picks_kr/private/events.jsonl` | 대상 월, 공급자 기준일, 발표시각 또는 미상, 확보시각, 서버 수신시각, 확인자, 파서 버전, 정정 전후 해시 |
| 월별 선정·가격·평가 | `research/external_picks_kr/private/forward/<YYYY-MM>/` | 확정 명단·비중, 선정 이유, 가격·기업행사 입력, 비용, 월별 결과와 각각의 해시 |
| 공개 가능한 연구 기록 | `research/external_picks_kr/PREREGISTRATION_KR_PRO_CONSENSUS_v1.md`·`LOCK.json`·`OPERATIONS.md` | 규칙·버전·해시·기간·제약. 유료 명단과 종목별 지표 제외 |

추가 원칙:

- 기존 `.txt`·`out/*.csv`는 덮어쓰거나 이동하지 않고 그대로 보존한다. 현재 연구 폴더는 Git 미추적 상태이므로 **폴더 전체 일괄 추가를 금지**하고, 원문·산출물을 명시적으로 제외한다.
- 원문은 해시만 남기는 것으로 끝내지 않는다. 비공개 백업에 실제 파일을 보관하고 복구를 확인한다.
- 정정은 새 버전으로 추가한다. 당시 확정 명단과 선정 결과를 사후 교체하지 않는다.
- PDF 두 건과 추출문은 확인했지만, 지정 다운로드 폴더에서 2026년 2월 원본 CSV는 확인되지 않았다. 해당 원본은 확보 전까지 `missing`으로 기록하며 추정 복원하지 않는다.

### 4. 월별 선정 규칙은 하나만 잠근다

신규 연구 ID는 **`KR-PRO-CONSENSUS-v1`**로 한다.

| 항목 | 고정 규칙 |
|---|---|
| 선정 | `S_m = V_m ∩ L_m`, 공통 종목 전부 |
| 비중 | 연구 포트폴리오에서는 동일 비중. 공통 종목 0개면 현금 100%, 현금수익률 0 |
| 종목 수 | 상위 N개 선발·임의 보충 없음 |
| 연속 편입 | V·L별 전월 잔류, 신규, 이탈, 연속 편입 개월 수를 기록하되 선정·비중에 사용하지 않음 |
| 재무·업종 | PER·ROE·시총·금융 비중은 설명·집중도 점검에만 사용. 추가 필터 없음 |
| 사용자 판단 | 후보 확인·선택·제외 사유를 별도 기록. 연구 포트폴리오의 성과와 사용자 선택 성과를 분리 |

공통 종목이 2개라면 연구상 종목당 50%가 된다. 이를 그대로 표시하고 **실제 자금배분 권고로 전환하지 않는다.**

버린 대안은 `L_hold`, 공통이면서 연속 편입, 두 명단 점수 합산, PER·ROE 재순위화다. 이미 본 결과를 따라 조건을 계속 붙이는 것을 피하고, 이번에는 공통 편입 가설 하나만 검증한다.

### 5. 발표·확보 시점을 지키는 평가 시계

기존 `external_picks.py`는 입력 날짜와 서버 생성일의 차이가 **7일 이내면 소급 입력으로 분리하지 않는다.** 따라서 기존 `is_backfilled()` 결과를 새 연구의 전향 적격 증거로 사용하지 않는다.

| 항목 | 새 연구의 규칙 |
|---|---|
| 사전등록 | 2026-10-31 23:59 KST까지 문서·실행기·비용·판정 규칙 잠금. 기한을 놓치면 11월을 소급 편입하지 않고 새 시작월을 등록 |
| 매월 확정 마감 | 해당 월 **첫 KRX 거래일 18:00 KST**까지 V·L 모두 서버에 수신·확정 |
| 연구 진입 | 그다음 KRX 거래일 시가 |
| 연구 교체 | 다음 달 동일 절차로 정한 거래일 시가. 마지막 달도 다음 교체 시가까지 평가 |
| 지연·누락 | 늦게 받은 명단은 별도 참고 기록만 가능. 공식 월을 소급 생성하거나 다른 달로 대체하지 않음 |
| 시각 증거 | 사용자 입력 날짜가 아닌 서버 수신·확정 시각과 불변 스냅샷 사용 |
| 거래일 | 검토된 KRX 달력 재사용. 단순 평일 계산 금지 |

이는 InvestingPro의 월 1일 리밸런싱 성과 복제가 아니라 **사용자가 확보한 두 명단으로 실행 가능한 시점부터 검증하는 연구**다. V·L·S·벤치마크 모두 같은 평가 구간을 사용한다.

현재 엔진 달력은 2026·2027년만 등록되어 있다. 2028년 일정은 검토된 달력 확보 전까지 추정하지 않으며, 해당 연도 관측 전에 별도 등록·검증한다.

### 6. 비교 지표와 최종 판정

| 구분 | 매월 누적할 항목 |
|---|---|
| 구성 | V·L·교집합·각 명단 단독 종목 수, 합집합 대비 교집합 비율, 신규·잔류·이탈, 업종 비중 |
| 종목 | 동일 기간 수익률, 벤치마크 대비 초과수익, 선정 당시 특징과 출처 |
| 포트폴리오 | V·L·S의 비용 전후 월수익률, 복리 누적, 회전율, 최대 종목 비중, 일별 평가금액 기준 MDD |
| 비교 | S−V, S−L, KODEX200(069500)·200동일가중(252650) 대비 성과 |
| 자료 품질 | 명단·가격·기업행사 누락, 확정 시각, 미완결 기간, 입력·실행 버전 |

새 전향 계산은 **KRX 가격 기반, 분할·병합 보정, 배당 미포함 가격 성과**로 통일한다. 배당을 포함한 총수익 우월성으로 설명하지 않는다.

- 주식 포트폴리오 비용은 기존 연구와 같은 **매수 6.5bp·매도 24.5bp**를 연구 가정으로 고정한다. 종목별 비중 변화에 적용하고 최초 진입·최종 청산도 포함한다.
- ETF는 비용 0의 가격 기준선으로 명시한다. 기존 기록기의 ‘교체당 0.1%’와 혼용하지 않는다.
- 가격 누락 종목을 빼고 나머지 비중을 재조정하지 않는다. 거래정지·상장폐지·기업행사 처리 규칙을 잠금 전에 명시하고, 해결되지 않은 평가 누락은 판정을 막는다.

판정 일정과 조건은 다음으로 고정한다.

| 항목 | 결정 |
|---|---|
| 표본 | 보유 시작월 2026-11~2028-10의 고정 24개월. 종목 수를 독립 표본 수로 세지 않음 |
| 중간 보고 | 2027-11-15까지 12개월 기술통계만 보고. 채택 판정 없음 |
| 최종 판정 | 마지막 보유분의 다음 교체 시가 확보 후, 2028-11-15까지 1회 |
| 주 검정 | 월별 비용 후 `S−V`, `S−L` 각각 평균 초과수익의 단측 검정. Newey–West 지연 3, t 기준 자유도 23, 두 비교에 Holm 보정·가족 오류율 5% 적용 |
| `PASS_REVIEW_ONLY` | 두 비교 모두 평균 초과수익 양수이고 보정 후 통과. 추가로 S 누적수익률이 KODEX200 이상이고 일별 MDD도 KODEX200보다 악화되지 않아야 함 |
| 그 외 | 어느 주 비교의 평균이 0 이하이면 `REJECT`; 양수지만 통계·시장·위험 조건 미달이면 `INCONCLUSIVE`; 필수 월·평가자료 누락이면 `INVALID` |
| 적용 | PASS도 적용 검토 자격만 부여. 사용자 승인·후속 변경 기록·배포 절차 없이 운영 반영 금지 |

매달 공개되는 결과는 개발에도 노출된 표본이다. 중간 결과를 보고 규칙을 바꾸면 새 버전·새 사전등록·이후 새 표본으로 시작하며, 기존 관측을 새 holdout으로 재사용하지 않는다.
