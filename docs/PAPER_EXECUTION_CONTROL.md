# 모의 주문 위험 통제

실제 가격 백테스트 전략의 주문 제안을 승인하면, 실제 증권계좌나 `portfolios` 장부를
변경하지 않고 `paper_fills`에만 모의 체결을 기록한다.

승인 시점에는 사용자별 위험정책을 다시 읽고 다음 항목을 강제한다.

| 통제 | 동작 |
| --- | --- |
| 모의 계좌 현금 | 사용 가능 현금을 넘는 매수 수량은 자동 감액 |
| 단일 종목·업종·외화 비중 | 체결 후 비중이 한도를 넘으면 가능한 최대 수량으로 자동 감액 |
| 이미 정책을 위반한 모의 장부 | 새 매수 차단 |
| 매도 | 전략별 모의 보유수량을 넘는 매도는 차단 |

VaR·MDD는 한 주문만으로 신뢰성 있게 재계산할 수 없어 주문 수량 통제에는 쓰지 않고,
포트폴리오 위험 화면의 경고 지표로 유지한다.

모의 계좌는 기본 `10,000,000 KRW`이며 첫 모의 체결 전
`PUT /api/strategy/paper-account`로 `initial_capital_krw`를 설정할 수 있다. 체결 뒤에는
원장 해석이 바뀌지 않도록 변경을 막는다. 모의 체결은 실제 보유자산과 완전히 분리된다.

## 대시보드

`GET /api/strategy/paper-dashboard`는 모의 체결 원장을 집계해 현금, 열린 포지션,
전략별 실현·미실현 손익, 총자산을 반환한다. 열린 포지션은 현재 지연 시세로만 평가한다.
자산곡선의 체결 시점 점은 평균 취득원가 기준이며 마지막 점만 현재 시세 평가이므로,
과거 일별 시가평가 곡선으로 해석하면 안 된다.

## 일별 성과 기록

평일 **18:10 KST**에 체결 이력이 있는 모의 계좌를 평가해 `paper_daily_snapshots`에
저장한다. 같은 KST 날짜에 다시 저장하면 최신 지연 시세 평가값으로 갱신된다.
화면의 **오늘 평가 저장** 또는 `POST /api/strategy/paper-dashboard/snapshot`으로도 수동
기록할 수 있다.

`GET /api/strategy/paper-dashboard/history?period=3m`는 저장된 일별 스냅샷으로 기간
수익률·MDD·연환산 변동성·Sharpe를 계산한다. 유효한 스냅샷이 부족하거나 시세 평가가
실패한 날은 성과 계산에 포함하지 않는다.

## 리밸런싱 알림함

5분 주기의 시세 캐시 갱신 뒤, 모의 체결 또는 대기 주문 제안이 있는 계정의 알림을
동기화한다. 알림 종류는 단일 종목·업종·외화·일별 손실 한도 초과, 현재 시세 확인 실패,
대기 중인 전략 주문 제안이다.

`POST /api/strategy/alerts/refresh`는 수동 동기화, `GET /api/strategy/alerts`는 활성 또는
처리 이력 조회를 제공한다. `POST /api/strategy/alerts/{id}/resolve`의 `acknowledged`,
`deferred`, `resolved` 액션은 검토 이력만 남기며 **주문을 실행하거나 승인하지 않는다**.
실제 모의 주문 승인은 기존 주문 제안 API에서만 수행한다.

## 감사·리서치 리포트

`GET /api/strategy/paper-report?period=3m`는 기간별 성과, 위험정책·활성 알림,
전략별 성과, 체결 원장, 일별 스냅샷, 알림 처리 이력을 읽기 전용으로 묶는다.
`GET /api/strategy/paper-report/export?period=3m&format=csv` 또는 `format=json`은
같은 내용을 다운로드한다. CSV는 스프레드시트 감사용 행 형식이며, JSON은 재현 가능한
원본 요약이다. 리포트는 서버에 별도 파일로 저장하지 않고 요청 시 생성한다.
