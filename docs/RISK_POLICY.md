# 포트폴리오 위험 정책

사용자별 정책은 `PUT /api/portfolio/risk-policy`로 저장하고,
`GET /api/portfolio/risk`에서 실제 가격 이력 기반 위험 지표와 함께 평가한다.

기본 경고 한도는 다음과 같다.

| 항목 | 기본 한도 |
| --- | ---: |
| 단일 종목 비중 | 35% |
| 단일 업종 비중 | 50% |
| 외화 자산 비중 | 60% |
| 1일 Historical VaR (95%) | 3% |
| 분석 기간 MDD | 30% |
| 일일 모의 계좌 손실 | 3% |
| 목표 연환산 변동성 | 15% |

현재 단계의 한도는 포트폴리오 변경을 막지 않는 **경고·권고**다. 실제 주문 전 차단은
다음 모의주문/OMS 단계에서 주문 수량과 체결 예상가를 기준으로 연결한다.

업종 노출은 포트폴리오 보유 항목의 선택적 `sector` 값으로 계산한다. 미입력 종목은
`미분류`로 표시되며 업종 한도 경고에서는 제외한다. 외화 자산의 과거 환율 변동은
아직 VaR·CVaR 시계열에 반영하지 않는다.
