# 퀀트 운영 런북

이 문서는 개인 퀀트 시스템의 **모의운영** 점검 절차다. 모든 항목은 사람의 검토를
전제로 하며, 화면의 경고·재검증·샌드박스 점검이 주문, 실거래 권한, 데이터 수정,
외부 메시지 발송을 자동 실행하지 않는다.

## 1. 워크포워드 재검증 경고

1. `내 전략 → 워크포워드 재검증`에서 기준 연구와 최신 재검증의 데이터 지문·수익률·Sharpe·MDD 차이를 확인한다.
2. 데이터 지문이 바뀌었거나 성과 저하 경고가 있으면 연구의 입력 기간·비용·팩터 필터를 확인한다.
3. 결론은 `전략 중단·재검토 의사결정 이력`에 사람의 메모로 남긴다.
4. 전략 승인 상태나 모의 주문 권한을 자동으로 바꾸지 않는다.

## 2. 통합 노출 경고

1. `통합 리스크`의 실제 보유 장부와 모의 원장 중복 종목을 확인한다.
2. 이 값은 두 장부를 나란히 합친 참고용 프록시이므로 실제 순자산·VaR로 해석하지 않는다.
3. 집중도 또는 -10% 충격 참고 손실을 검토하고, 실제 보유 변경은 별도의 포트폴리오 화면에서 사용자가 직접 수행한다.

## 3. 데이터·운영 경고

1. 데이터 계보 카드에서 `메타데이터 보완 필요`·`데이터 없음` 종목을 확인한다.
2. 시장 데이터 운영 경고와 후보 기준선 최신성을 확인한다.
3. 외부 메시지(메일·Slack 등)는 이 시스템에서 자동 발송하지 않는다. 필요 시 운영자가 승인된 채널로 수동 전파한다.

## 4. 로컬 브로커 샌드박스 계약 검증

1. `로컬 샌드박스 계약 검증`을 실행한다.
2. 유효 형식 수락, 잘못된 형식 거절, `live_capable=false`를 확인한다.
3. 결과는 감사 원장에 남지만 증권사 API·계좌·자격증명·네트워크를 사용하지 않는다.
4. 이 통과 결과만으로 실거래를 활성화하거나 주문을 전송할 수 없다.

## 금지된 자동 행위

- 실거래 주문 제출 또는 실거래 권한 부여
- 실제 보유 포트폴리오 수정
- 과거 시세 데이터 정정·삭제
- 외부 알림 발송
- 전략 승인·중단 상태 변경
