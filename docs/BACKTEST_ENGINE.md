# 백테스트 엔진 표준

`/api/strategy/backtest`는 `backtest_engine.py`의 일봉 롱/현금 MA 크로스오버
엔진을 사용한다. 이는 투자 권유나 주문 실행 시스템이 아니다.

## 고정 규칙

- MA 신호는 거래일 `t` 종가로 계산한다.
- 신호 변경은 `t+1` 거래일 시가에 체결된 것으로 처리한다.
- 거래비용과 슬리피지는 매수·매도 각각의 편도 체결에 적용한다.
- 전략 수익률은 이전 보유 상태의 전일 종가→당일 시가 수익률과 새 보유 상태의 당일
  시가→종가 수익률을 합산하고, 해당 일의 체결 비용을 차감한다.
- 벤치마크는 기본적으로 동일 종목 Buy & Hold이며, 지정한 벤치마크는 전략 거래일에 맞춰 정렬한다.

응답의 `execution`에는 엔진 버전, 실행 ID, 입력 OHLC fingerprint, 초기자본,
비용 모델과 체결 규칙이 포함된다. 같은 입력 데이터·티커·파라미터는 같은 `run_id`를
생성한다. 저장 전략의 `snapshot.backtest_execution`도 이 메타데이터를 보존한다.

## 한계

일봉이라 장중 체결·호가 단위·상하한가·세금·환전 비용·유동성 충격은 아직 모델링하지
않는다. 다음 단계의 위험 및 포트폴리오 관리 전에 실거래 성과로 해석하면 안 된다.
