**사용자 "5C 국면 B 실행해" 승인(2026-09-09)에 따라 실행.** 이로써 **잠금구간 2002-10-14~2016-08-31은 합의15 §6에 따라 `consumed` 상태다.** 이후 구현 버그가 발견되더라도 결과만 무효 처리되며, 구간 자체는 복원되지 않는다.

### B-1. 실행 이력 — 시도 2회, 성과 출력 1회

투명성을 위해 실행 시도 전부를 기록한다.

**시도 1 (실패, 출력 없음)**: `stage5c_run_locked_window.py` (sha256 `ef86f1dc…`) 실행이 `json.dumps` 지점에서 `TypeError: Object of type int64 is not JSON serializable`로 중단됐다. 원인은 순수 직렬화 문제 — `Signal.hold`가 dataclass 선언 타입 `bool`이 아닌 `np.bool_`, `Metrics`의 값들이 `float`이 아닌 `np.float64`였다. **이 시도에서 성과 수치는 단 하나도 출력되지 않았다**: 크래시 지점이 스크립트의 모든 `print`문보다 앞이며, `stage5c_result.json`도 생성되지 않았음을 파일 목록으로 확인했다. §6의 소비 트리거(사전등록된 성과의 출력)에 해당하지 않으므로 구간 상태는 불변으로 처리했다.

**수정 (계산 비영향 실증)**: `compute_signals`에서 `float(excess)` / `bool(excess > 0)`, `compute_metrics`에서 `float(...)` 캐스팅만 적용했다. 계산식은 한 줄도 변경하지 않았다. 이 수정이 결과에 영향을 주지 않음을 **잠금구간을 열기 전에** 실증했다 — 이미 소비된 2016~2026 스모크 테스트를 재실행해 수정 전 값과 완전히 동일함을 확인했다(판정 110회/보유 67/현금 60→43, 추세 CAGR 16.2894%·MDD 40.9289%, B&H 17.3851%·MDD 40.9289%, Calmar·월간승률 전부 일치). 회귀 방지 단위 테스트 1건을 추가해 총 26건(collection 16건 포함 42건) 전부 통과.

### B-3. 최종 판정: **INCONCLUSIVE**

개정4에서 **결과를 보기 전에** 확정한 §10 매트릭스의 "CAGR 악화 × MDD 개선" 칸이 그대로 적용됐다. 이 칸이 판정을 가를 가능성이 높다는 점은 국면 B 승인 요청 시점에 이미 사용자에게 고지했고, 실제로 그 칸에 떨어졌다.

**§5에 따른 귀결**: INCONCLUSIVE는 **전향적 섀도 축적만** 허용한다. 슬리브 연구 후보 승격 아님, 라이브 반영 아님, 파라미터 변경 후 재시도 아님. 이 구간은 소비되었으므로 동일 구간에서의 재검증은 불가능하다.

### B-4. 결과 해석 시 유의사항

- **MDD 개선폭은 컸다** (52.69% → 29.73%, 22.96%p). 낙폭 절반 감소는 이 슬리브 도입의 핵심 근거에 부합하는 방향이며, Calmar도 0.177 → 0.258로 개선됐다. 그럼에도 판정이 PASS가 아닌 것은 CAGR이 1.66%p 악화됐고, 확정된 매트릭스가 "CAGR 악화 + MDD 개선"을 PASS로 인정하지 않기 때문이다.
- **155회 판정은 독립표본이 아니다** (§3 명시). 12개월 룩백이 겹치므로 유효 표본 수는 훨씬 적다.
- 국면 A에서 확인된 **"월말 판정은 한 달 안에 종료되는 급락에 반응할 수 없다"** 는 한계는 이 구간에서는 상대적으로 덜 작동한 것으로 보인다 — 2008년 낙폭이 여러 달에 걸쳐 진행되어 월말 판정이 현금으로 빠질 시간이 있었기 때문으로 추정된다. 다만 이는 사후 해석이며 사전등록된 검정 대상이 아니다.
- **§10 비교기준선 (b)는 미산출**이다(데이터 부재, 개정4 A-3 참조). 기준선 (a) D-25 전기간 4.01% 결정적 CAGR 대비로는 추세 7.66%·B&H 9.33% 모두 상회하나, 이는 단일종목 ETF와 다종목 시스템의 비교라 직접 대응하지 않는다.
- **Stage 5B의 제약이 그대로 승계된다**: 잠금구간의 2010년 이전 절반가량은 공식 소스 대조가 수행되지 않았고, 무결성 근거는 Stage 3.5A 구조적 검증에 한정된다(개정3 참조).
