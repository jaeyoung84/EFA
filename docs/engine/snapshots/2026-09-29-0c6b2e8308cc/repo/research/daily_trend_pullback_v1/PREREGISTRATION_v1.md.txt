## 1. 왜 이 변형인가 — 정직한 탐색 이력 (D-36 항목 "honest exploration history")

1. T-0(v0.4-rc1)의 실DB 관측 #1(2026-09-11, 창 2022-01-01~2026-09-08)은 646거래·불통과였다(DECISIONS D-38, 로그 §5.0).
2. 외부 AI 토론(로그 §5.0 P-1~P-7)에서 인과가 정리됐다: **C-3** 확장 방향 랭킹(return20·dist_sma50·vol_ratio·rsi 상위) →
   **C-2** 10EMA 이탈 청산이 청산의 473/646(73.2%)·평균 5.69일로 우측 꼬리를 절단 → **C-1** 승률 26.2% < 손익분기 손익비 2.82.
3. 따라서 v1 의 규칙(랭킹 방향 반전·ema_cross 청산 삭제)은 **관측 #1 의 결과를 보고 만든 규칙**이다. 이 창(2022-01-01~2026-09-08)에서
   v1 이 좋아 보여도 그것은 "아이디어의 표본 내" 결과이며, 독립 표본은 남아 있지 않다(로그 §1.7 홀드아웃 소진).
4. 그러므로 관측 #2 의 결과 등급 상한은 **힌트**(①b)이고, 적용 여부의 실제 판단은 §6 전향 관측(FORWARD_START 이후 새 가격)에서만 한다(D-26 3항).
5. 사전에 규정한 것: 관측 #2 는 1회만 실행하고 창을 소비한다. 결과를 보고 파라미터·가중치·청산을 바꿔 재실행하지 않는다.
   바꾸고 싶으면 새 변형(v2)·새 사전등록·새 관측 번호(#3)다.

### 3.3 사전 규정 실패 조건 (관측 #2)
| 조건 | 내용 | 성격 |
|---|---|---|
| F-a | 거래 수 < 30 | 판정 |
| F-b | R1(보수 하한 PF > 1.00, Bonferroni 0.0125 분위) False | 판정 |
| F-c | R3(MDD ≤ 20%) False | 판정 |
| F-d | TrendGoal 미통과 (5개 기준 중 하나라도 False) | 판정 |
| F-d' | D-37 즉시기각선(비용후 평균수익 ≤ 0) 해당 | 판정 |
| F-e | holding_limit 청산 비중 > 50% (ema_cross 삭제가 단순히 청산을 15일 강제청산으로 옮겼을 뿐인지 진단) | 진단 |
| F-f | ㉮ 통과율 20~80% 밖 (권고 발생) | 권고 |

- 판정 조건(F-a~F-d') 하나라도 해당 → "불통과 힌트". 전부 미해당 → "힌트"(전향 관측 진행 근거). **어느 쪽이든 PASS 는 아니다**(①b, 독립 표본 없음).
- 검정력 라벨은 관측 #1 처럼 "검정력 부족"으로 나올 가능성이 높다(n_eff 상한 = 거래일/평균보유일). 이는 실패 조건이 아니라 등급 상한(힌트)의 근거다.
- "불통과 힌트"라도 규칙을 고쳐 이 창에서 재실행하지 않는다. 창은 소비된다.
