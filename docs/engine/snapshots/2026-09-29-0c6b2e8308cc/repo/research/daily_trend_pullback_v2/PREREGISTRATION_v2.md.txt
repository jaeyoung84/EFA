## 1. 왜 이 변형인가 — 정직한 탐색 이력 (D-36 항목 "honest exploration history")

1. 같은 창(2022-01-01~2026-09-08)에서 이미 두 번 관측했다: 관측 #1 = T-0 v0.4-rc1(646거래, 불통과, D-38) → 관측 #2 = v1.0-rc1(347거래, 불통과 힌트, **D-37 즉시기각 True**, D-39).
2. v1 의 두 교정(V1-3 눌림 방향 랭킹·V1-4 ema_cross 청산 삭제)은 청산 분포에 의도대로 나타났으나(ema_cross 473→0, 평균 보유 5.69→11.18일, 승률 26.2%→33.1%)
   기대값(C-1)은 해결되지 않았다(TrendGoal 5기준 중 4개 False, R1·R3 False). 남은 후보 = 진입 정의(무변경 블록) · **C-5 시장필터** · C-8 구간 특성(로그 §5.0 P-7, 방향 미확정).
3. v2 는 그중 **C-5 하나만** 교정한다. 근거는 성과가 아니라 설계 정합성이다:
   - 유니버스는 KOSPI+KOSDAQ 전체(H-16, 3,161종목)인데 국면 게이트는 069500(KODEX 200, KOSPI200) 하나였다 → KOSDAQ 종목이 KOSPI 국면으로 게이트된다.
   - 저장소 공식 규칙 `src/korea_quant/eligibility.py` 는 시장별 벤치마크(`DEFAULT_MARKET_BENCHMARKS`: KOSPI→069500, KOSDAQ→229200)로 `market_regime_entry_allowed`
     (전일 종가 > SMA, 다음 세션 시가 체결) 를 적용한다. v2 는 연구 코드를 이 규칙과 정렬한다(읽기만 하고 저장소 코드는 수정하지 않음).
   - **방향은 사전에 예측하지 않는다.** KOSDAQ 종목의 게이트가 229200 으로 바뀌면 거래 수가 늘 수도 줄 수도 있다(only_KOSDAQ 일에는 늘고 only_KOSPI 일에는 줄어듦). 관측 #3 이 보는 것은
     "시장별 정렬이 기대값 부호(D-37 즉시기각선)를 바꾸는가"이지 "좋아지는가"가 아니다.
4. 관측 #1·#2 의 결과를 본 뒤 만든 규칙이므로 관측 #3 의 결과 등급 상한은 **힌트**(①b)다. 독립 표본은 없다(로그 §1.7). 적용 여부의 실제 판단은 §6 전향 관측(FORWARD_START 이후 새 가격)에서만 한다(D-26 3항).
   다중 관측은 `declared_observations = 3` 으로 정직하게 반영한다(R1 Bonferroni 분위 = 0.05/(2·3) = 0.008333…).
5. 탐색된 파라미터는 없다: SMA 창 50·자금관리·비용·랭킹·청산 전부 v1 과 동일하고 **바뀌는 것은 벤치마크 매핑뿐**이다. 229200 의 실DB 데이터는 관측 #3 전에 행수·기간(2,460행, 2016-08-29~2026-09-09, market='ETF')만 확인했고
   SMA·게이트 ON 일수·시장별 거래 건수는 실행 전에 산출하지 않았다(V2-4 진단은 관측 #3 실행 시 처음 산출되어 §8 에 기록).
6. 사전에 규정한 것: 관측 #3 은 1회만 실행하고 창을 소비한다(3회째). 결과를 보고 벤치마크·SMA·파라미터를 바꿔 재실행하지 않는다. 바꾸고 싶으면 새 변형(v3)·새 사전등록·새 관측 번호(#4)다.

### 3.3 사전 규정 실패 조건 (관측 #3)
| 조건 | 내용 | 성격 |
|---|---|---|
| F-a | 거래 수 < 30 | 판정 |
| F-b | R1(보수 하한 PF > 1.00, Bonferroni 0.00833 분위) False | 판정 |
| F-c | R3(MDD ≤ 20%) False | 판정 |

- 판정 조건(F-a~F-d') 하나라도 해당 → "불통과 힌트". 전부 미해당 → "힌트"(전향 관측 진행 근거). **어느 쪽이든 PASS 는 아니다**(①b, 독립 표본 없음).
- 검정력 라벨은 관측 #1·#2 처럼 "검정력 부족"으로 나올 가능성이 높다(n_eff 상한 = 거래일/평균보유일). 실패 조건이 아니라 등급 상한(힌트)의 근거다.
- "불통과 힌트"라도 규칙을 고쳐 이 창에서 재실행하지 않는다. 창은 소비된다(3회째).

### 3.4 관측 #2 대조 (비교 분석 ②)
- 같은 DB·같은 창·같은 비용·같은 자금관리·같은 랭킹·같은 청산에서 **게이트 매핑(V2-2·V2-3)만** 다르다. 대조는 건수·분포·플래그 줄 단위(래퍼 §5)로 한다:
  거래 수, 시장별 거래 건수, exit_reason 분포, 승/패 건수, holding_days 분포, 무포지션 일수, R1/R3/최종_통과 플래그, TrendGoal 5기준, 즉시기각 여부, ㉮ 건수(동일 기대).
- 해석 틀(사전 고정): (i) 즉시기각 True 유지 → C-5 는 기대값 부호의 원인이 아니며 남는 후보는 진입 정의·C-8(사용자 결정 사안). (ii) 즉시기각 False 로 전환 → 시장별 정렬이 부호를 바꾼 힌트이나 표본 내 결과이므로 §6 전향 관측으로만 검증.
  (iii) F-g 해당 → 게이트 퇴화이므로 (i)/(ii) 어느 쪽이든 해석 보류.
- 해시(trades/equity)는 규칙이 다르므로 상이한 것이 정상이다. 관측 #2 해시(b4feeacd358e5e48 / 135f9916ffee2426), 관측 #1 해시(d6d1778e6a49bda7 / 013e2d14359ff6cb)는 기록용.
