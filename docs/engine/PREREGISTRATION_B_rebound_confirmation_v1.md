# 사전등록 B-1 — 볼린저 RSI "반등 확인 후 진입" 전향 관측 (v1)

- 등록일: 2026-10-07 (KST). 등록자: Claude Code. 근거: 클로드코드·코덱스 합의안 3번, 사용자 승인("단계별로 진행").
- 성격: **관측 전용 가설 하나.** 실제 추천·게시·순위·청산 규칙, 사용자 수동 원장, 필터 OFF 전향 표본(EINT-023 이후)과
  분리한다. 주문·자동 모의체결·포지션은 만들지 않는다. 결과가 좋아도 이 문서만으로 규칙을 바꾸지 않는다.
- 과거 자료로 고르지 않는다: D-20·D-21 구간은 소진됐다. 아래 정의는 과거 백테스트를 돌려 고른 값이 아니며, 등록 뒤에는
  바꾸지 않는다. 바꾸면 v2로 새로 등록하고 표본을 0부터 다시 센다.

## 1. 대상 표본

- 엔진이 게시한 v2 추천 중 **swing(Bollinger-RSI) 아이템의 선정된 진입 신호 전부**(순위 무관).
- 신호 기준일 D(`data_as_of`)가 **2026-10-07 이후**인 것만. 등록 전에 게시된 신호는 넣지 않는다.
- 같은 종목이 다른 날 다시 신호를 내면 별도 표본이다(실제 추천과 같은 단위).

## 2. 두 갈래 (짝 비교)

| 갈래 | 진입 |
| --- | --- |
| **A. 원래 규칙** | D 다음 거래일(S1) **시가** |
| **B. 반등 확인** | S1 **종가**가 ① S1의 볼린저(20, 2σ) 하단보다 높고 ② D 종가보다 높으면 확인 → 그다음 거래일(S2) **시가**. 둘 중 하나라도 아니면 **진입 안 함**(수익 0으로 셈) |

- 확인은 S1 종가로만 판단한다(장중 값·S2 시가는 보지 않는다 → 미래 정보 없음).
- 지표 계산은 실제 엔진과 같은 함수(`bollinger_rsi_signals`: SMA20·모집단 표준편차·Wilder RSI14)와 같은 이력 길이(730일)다.

## 3. 청산 (두 갈래 공통, 현재 규칙 그대로)

- 진입한 거래일부터 매 거래일 **종가**로 `종가 ≥ 볼린저 중간선(20)` 또는 `RSI(14) ≥ 50`을 확인하고, 충족하면 **다음 거래일 시가**에 청산.
- 가격 손절·보유기간 상한은 없다(D-3·D-4).
- 거래정지 봉(시가·고가·저가 0)은 그날 진입·청산하지 않고 다음 정상 봉으로 넘긴다. 상장폐지 등으로 봉이 없으면 `missing_bar`로 멈추고 판정에서 뺀다.

## 4. 비용 (감사 문서 `AUDIT-2026-10-07-reversion-data.md` 기준, 고정)

- 매수: 수수료 0.015% + 슬리피지 0.05%. 매도: 수수료 0.015% + 거래세 0.20% + 슬리피지 0.05%.
- 순수익률 = 청산가×(1 − 0.00015 − 0.0020 − 0.0005) ÷ (진입가×(1 + 0.00015 + 0.0005)) − 1.

## 5. 판정

- **주 지표:** 신호마다 `d = B 순수익률 − A 순수익률`(B 진입 안 함은 0). 두 갈래가 모두 끝난(청산됐거나 B 미진입이고 A 청산) 신호만 센다.
- **판정 시점:** 끝난 짝이 **100개**가 되는 첫 파이프라인 실행, 또는 **2028-10-07** 중 먼저 오는 때. 그 전에는 기술 통계만 표시하고 판정하지 않는다.
- **방법:** d의 평균과 부트스트랩 95% 신뢰구간(재표본 10,000회, 시드 20261007, 신호 단위 복원추출).
  - **PASS**: 평균 > 0 그리고 하한 > 0 → "규칙 변경을 사용자에게 제안할 수 있음"(자동 채택 아님).
  - **FAIL**: 상한 < 0 → B 가설 종료.
  - **INCONCLUSIVE**: 그 밖 → 채택하지 않음. 연장은 새 등록(v2)으로만.
- **보조(기술 통계, 판정에 쓰지 않음):** B 진입률, 갈래별 평균·승률·평균 보유 거래일, 최대 역행.

## 6. 기록

- 엔진 일일 파이프라인이 게시 뒤 `state/rebound-shadow.json`(스키마 `kqs-rebound-shadow/v1`)을 원자적으로 쓴다. 실패해도 게시는 바뀌지 않는다.
