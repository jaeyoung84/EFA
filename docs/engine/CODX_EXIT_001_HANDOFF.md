# CODX-EXIT-001 청산 표시 1차 수정·후속 인계

<!-- Codex 수정: CODX-EXIT-001 (2026-10-12), 파일 전체. -->

## 완료 범위

- 추천 카드의 '검증된 청산 규칙' 표현을 '현행 청산 참고 기준'으로 정정했다. v4의 추천 시점 가격선은 기준일 종가로 만든 **근사치**다. 실제 보유 손절선은 매수가, 추적선은 보유 중 최고 종가에 의존한다.
- 보유 종목 v4의 종가 손절·트레일링 감지는 `signal_basis=close_warning`으로 따로 표시한다. 기존 API `state=exit_signal`은 호환을 위해 유지했다. 화면의 '매도 신호' 확정 집계에는 넣지 않는다. 시장 레짐·15거래일 및 평균회귀 종가 관측은 `rule_observed`다.
- 엔진 추천·청산 계산, 자동 주문, 수동 원장, 배포는 변경하지 않았다. 이 수정은 성과 개선이나 신규 청산 규칙 채택이 아니다.

## 미완료: 별도 전향 관측 후보

**후보 가설:** Pullback v4 보유 중 해당 시장 ETF 종가가 50일 단순이동평균 이하인 날 **2거래일 연속** 확인되면 그다음 거래일 시가를 청산 참고 시점으로 삼는다. 현재 v4의 1일 확인 규칙과 다른 것은 이 시장 청산 분기 한 가지뿐이다. 가격 손절·추적·15일 상한·진입·유니버스·우선순위는 바꾸지 않는다.

이 가설은 아직 코드·운영 수집·사전등록 판정 규칙으로 구현되지 않았다. 과거 2022-01-01~2026-09-08 Pullback 관측 #1~#5와 D-20/D-21 소진 구간을 다시 선택 근거로 쓰면 안 된다. 현재 D-43 v4 전향 표본에 새 규칙 결과를 합치거나 기존 추천을 조용히 바꾸면 안 된다.

Claude Code 또는 후속 담당자가 진행할 순서:

1. 원문 D-43과 최신 EINT, `AGENTS.md`를 다시 확인한다. A=현행 1일 확인, B=2일 연속 확인을 **새 게시일 이후의 독립 짝지은 전향 표본**으로 정의한다. 신호일·ETF 기준일·다음 시가·거래정지/결측 처리·비용·배당·동일 종목 중복·상장폐지·중도 미청산 처리, 표본 수/시한, 주지표/실패 기준을 관측 전에 문서로 고정한다. 이전 가격으로 가설을 골라서는 안 된다.
2. 관측 전용 shadow 수집기를 별도 출력/manifest에 구현한다. 매일 사용 가능 시점 이후 데이터만 사용하고 코드·설정·비용·기준일·자료 해시를 분리 기록한다. 기존 `rebound-shadow`, 추천/청산, 수동 원장과 섞지 않는다. 장부/주문/홈페이지 추천을 새 가설로 자동 변경하지 않는다.
3. 합성 시계열로 1일 이탈, 연속 2일, 중간 회복, 50일선 결측, 다음 거래일 갭, 타 청산 조건 우선순위와 look-ahead 금지를 검증한다. 이후 새 표본이 차고 사전등록 기준을 만족할 때에만 성과 비교·사용자 채택 결정을 별도로 요청한다.
4. AWS 반영이 필요하면 운영 대상·배포 검증·승인을 별도로 확인한다. 이번 로컬 작업은 AWS에 배포하지 않았다.
