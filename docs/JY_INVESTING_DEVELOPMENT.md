# JY investing 개발 방향

## 제품 정의

JY investing은 개인 투자자가 시장을 읽고, 전략을 검증하고, 자신의 포트폴리오 위험을 관리하기 위한 개인 퀀트 리서치 시스템이다. 자동매매 플랫폼이 아니라 **리서치와 모의 운용이 우선인 의사결정 도구**로 개발한다.

## 우선순위

1. 개인 포트폴리오를 등록하고 현재 상태를 확인한다.
2. 실제 가격 데이터와 가상·교육용 데이터를 화면과 API에서 명확히 구분한다.
3. 전략을 실제 가격 데이터로 백테스트하고, 거래비용·슬리피지·낙폭을 함께 검토한다.
4. 신호를 주문 제안으로 만들고 모의 체결로 검증한다.
5. 충분한 검증 뒤 증권사 계좌 조회, 최종적으로 승인 기반 주문 연동을 검토한다.

## 정보 구조

```text
대시보드       오늘의 시장·포트폴리오·전략 상태와 행동 항목
종목 탐색      시장, 종목, 재무, 공시, 기술·산업 분석
전략 연구소    백테스트, LEAN 결과, 파이프라인, 차트 연구
포트폴리오     보유 자산, 목표 비중, 리스크, 리밸런싱
리서치 자료실  거시경제, 밸류에이션, 재무제표, 학습 자료
설정·운영      계정, 데이터 상태, 세무·회계, 향후 증권사 연동
```

## 데이터 원칙

- 가격, 공시, 재무처럼 외부에서 받은 값에는 출처와 최종 갱신 시각을 표시한다.
- 시뮬레이션·고정 가정·사전 실행된 LEAN 결과는 실제 시세 및 실거래 성과와 혼동되지 않게 표시한다.
- 보유 종목과 거래 내역은 로그인 사용자별로 분리해 저장한다.
- 주문은 기본값으로 생성하지 않는다. 신호 → 리스크 검사 → 주문 제안 → 사용자 승인 → 모의 체결 순서로만 확장한다.

## 기술 경계

- 프런트엔드: 순수 JavaScript SPA를 유지하고, 화면별 모듈과 공통 디자인 토큰을 사용한다.
- API: FastAPI 라우터를 도메인별로 분리한다. 포트폴리오·보유종목 API는 인증이 필요하다.
- 저장소: MongoDB는 계정, 보유종목, 전략 설정, 모의 주문·체결 기록에 사용한다.
- 시계열 데이터: 현재는 외부 조회 데이터를 사용하며, 장기적으로는 PostgreSQL/TimescaleDB와 작업 스케줄러를 추가한다.
- 리서치 검색: Qdrant·Meilisearch는 문서 검색 용도로만 유지한다.

## 협업 규칙

- 기존 라우트와 화면은 명시적 합의 없이 삭제하지 않는다. 새 구조에서 보이지 않는 기능도 코드와 API는 보존한다.
- 화면에 새 숫자를 추가할 때 데이터 출처, 통화, 기준 시각, 실제/가상 여부를 함께 정의한다.
- 투자 성과를 표시할 때는 총수익률만 쓰지 않고 CAGR, MDD, Sharpe/Sortino, 비용 반영 여부를 함께 검토한다.
- API 스키마 변경 시 프런트엔드 호출부와 이 문서를 같은 변경 단위로 갱신한다.
- 비밀번호, API 키, 계좌번호, 실제 주문 토큰은 코드나 문서에 저장하지 않는다.

## 현재 단계와 다음 작업

Phase 2(개인 포트폴리오 기반) ~ Phase 5(운영 안정화)까지 문서화된 로드맵을 모두 완료했다. 자세한 구현 내역과 파일 지도는 `docs/CLAUDE_HANDOFF.md`를 참고한다.

- Phase 3: 실제 보유자산 리스크 분석
- Phase 4: 전략과 포트폴리오 연결(전략 저장, 실제 가격 백테스트, 주문 제안, 모의 체결)
- Phase 5: 운영 안정화 — TimescaleDB 이전 설계(`docs/TIMESERIES_MIGRATION.md`, 실제 도입은 미착수), 시세 캐시 예열용 인프로세스 scheduler(`app/backend/scheduler.py`), API 테스트(`tests/`), 프런트엔드 실제/지연/가상 데이터 표시 일관화

**다음 단계는 정해져 있지 않다.** "구현 시 반드시 지킬 것"에 실제 주문·증권사 계좌 연결은 구현하지 않는다고 명시돼 있으므로, 이후 작업은 사용자가 새로 요청할 때 그 내용에 따라 정한다.

데스크톱 실행 방법은 `docs/DESKTOP_SETUP.md`를 따른다. 기본 개인 실행은 경량 Docker Compose를 사용하며, 주문 전송 기능은 포함하지 않는다.
