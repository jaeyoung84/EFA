# Korea Quant System 읽기 전용 연동

`Ubuntu-26.04`의 `/home/gram/kqs-bridge`는 엔진 저장소·SQLite·파이프라인 로그·모의 CSV를
변경하지 않는 읽기 전용 서비스다. 홈페이지 백엔드는 `KQS_BRIDGE_URL`(기본
`http://127.0.0.1:18100`)의 `/api/all`에서 상태를 읽고, 로그인한 사용자에게만
`GET /api/kqs/status`로 축약 요약을 제공한다.

이 API는 스케줄러·파이프라인·DB 최신일·모의 포지션 수·전향 관측 판정·해시 잠금 요약만
반환한다. 원문 로그, 후보 전체 목록, 주문 실행 API는 프록시하지 않는다. 따라서 홈페이지는
엔진의 자동 파이프라인이나 전략·모의 CSV를 실행·수정할 수 없다.
