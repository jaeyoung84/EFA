개인정보처리방침

EFA — Economic Freedom Automation(https://efa-quant.com, 이하 "사이트") · 시행일 2026년 10월 1일

사이트는 KRX 일봉 자료로 계산한 전략 추천을 보여 주고, 회원이 직접 입력한 모의 매수·매도 판단을 기록·분석하는 개인 투자 연구 사이트입니다. 회원 가입과 로그인은 네이버 로그인으로만 받으며, 아래 범위에서만 개인정보를 처리합니다.

1. 처리하는 개인정보 항목

구분항목수집 방법
네이버 로그인네이버 회원 고유 식별자(필수), 이름(없으면 별명), 이메일 주소(회원이 동의한 경우)네이버 로그인 시 회원 동의를 거쳐 네이버로부터 제공받음
서비스 이용로그인 세션(암호화된 형태), 메뉴 이용 내역, 회원이 직접 입력한 매수·매도·관망 등 판단 기록과 메모회원이 사이트를 이용하거나 직접 입력할 때 생성
자동 생성접속 IP 주소, 접속 시각, 요청한 주소서버 접속 기록(보안·장애 대응용)

네이버 비밀번호는 사이트로 전달되지 않으며, 사이트는 이를 알 수 없습니다.

2. 이용 목적

  • 회원 식별과 로그인 상태 유지(네이버 회원 고유 식별자, 로그인 세션)
  • "내 계정" 화면에 이름과 이메일 표시
  • 회원 본인의 판단 기록·보유 현황·성과를 저장하고 본인에게만 보여 주기
  • 부정 접속 차단, 보안 사고와 장애 대응(접속 기록)

광고, 마케팅, 회원 정보 판매에는 사용하지 않습니다.

3. 보관 기간과 파기

  • 계정 정보(네이버 식별자·이름·이메일)와 이용 내역: 회원 탈퇴 시 즉시 삭제합니다.
  • 로그인 세션: 발급 후 14일이 지나거나 로그아웃·탈퇴하면 삭제합니다.
  • 네이버 로그인 진행용 보안 정보(쿠키·일회용 확인값): 10분 뒤 자동 삭제합니다.
  • 회원이 입력한 판단 기록: 탈퇴 후에는 회원 정보와의 연결이 끊긴 상태로 남을 수 있으며, 누구의 기록인지 알 수 없습니다.
  • 접속 기록: 보안·장애 대응을 위해 서버 로그에 보관하며, 그 목적 외에는 사용하지 않습니다.

4. 제3자 제공

사이트는 회원의 개인정보를 제3자에게 제공하지 않습니다. 법령에 따라 수사기관 등이 요청하는 경우는 예외입니다.

5. 처리 위탁과 국외 이전

받는 곳위탁 업무위치
Amazon Web Services서버·데이터 보관(호스팅)대한민국(서울 리전)
Cloudflare, Inc.웹 접속 전달과 보안(접속 기록이 경유)미국 등 Cloudflare 전 세계 네트워크

Cloudflare에는 사이트에 접속할 때 네트워크를 통해 접속 정보가 전달됩니다. 이 전달을 원하지 않으면 사이트 이용을 중단할 수 있습니다.

6. 회원의 권리와 행사 방법

  • 조회: 로그인 후 상단의 내 이름을 누르면 "내 계정" 창에서 이름·이메일·최근 이용 내역을 볼 수 있습니다.
  • 탈퇴(삭제): "내 계정" 창의 회원 탈퇴에서 바로 탈퇴할 수 있으며, 계정 정보·세션·이용 내역이 즉시 삭제됩니다.
  • 네이버 연동 해제: 네이버 > 내정보 > 이력관리 > 연결된 서비스 관리에서 이 사이트의 연결을 끊을 수 있습니다.

7. 쿠키와 브라우저 저장소

  • 네이버 로그인 중에만 보안 확인용 쿠키를 10분 동안 사용합니다.
  • 로그인 상태는 브라우저 저장소(localStorage)의 세션 값으로 유지하며, 로그아웃하면 지워집니다.
  • 광고·추적 목적의 쿠키는 사용하지 않습니다.

8. 안전성 확보 조치

  • 모든 접속은 HTTPS로 암호화되며, 서버는 Cloudflare를 거친 접속만 받습니다.
  • 로그인 세션은 원래 값 대신 암호화된 값(해시)으로만 저장합니다.
  • 회원 기록은 본인 계정으로 로그인한 경우에만 조회할 수 있습니다.

9. 투자 정보에 관한 안내

사이트의 추천과 성과 자료는 회원의 판단을 돕는 정보이며, 주문을 실행하거나 수익을 보장하지 않습니다.

10. 방침의 변경
