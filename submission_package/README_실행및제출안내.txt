[JY Investing 평가 및 시험 결과물 확인 안내]

제출자: 송재영 (경기도)
평가 결과: 주식 어휘력 평가 시험 30/30 만점 (100%)

----------------------------------------------------------------------
1. 웹 서비스 로컬 구동 방법 (택 1)
----------------------------------------------------------------------
[방법 1: docker-compose 사용 (추천)]
- 이 폴더(docker-compose.yml이 있는 위치)에서 터미널을 열고 아래 명령어 실행:
  docker compose up -d

[방법 2: 파일 없이 터미널 1줄 실행]
- 터미널(PowerShell, CMD, Bash) 어디서나 아래 명령어 1줄 실행:
  docker run -d -p 8000:8000 jaeyoungsong/jy-investing:latest

[방법 3: 도커 데스크톱(Docker Desktop) GUI 사용]
- Docker Desktop 검색창에 'jaeyoungsong/jy-investing' 검색 후 Run (Port: 8000)

----------------------------------------------------------------------
2. 접속 및 결과 확인
----------------------------------------------------------------------
- 웹 브라우저 접속 주소: http://localhost:8000
- 시험 결과 확인 메뉴: 상단 '리서치 자료실' -> '주식 어휘력 평가 시험'
  (직접 링크: http://localhost:8000/#vocabulary-exam)
- '송재영 (경기도) - 30/30 만점' 결과 및 30개 문항 상세 채점표가 자동 표시됩니다.

----------------------------------------------------------------------
3. 첨부된 파일 안내
----------------------------------------------------------------------
- docker-compose.yml: All-in-One 웹 애플리케이션 구동용 단독 컴포즈 파일
- vocabulary_exam_submission_raw.json: MongoDB에 저장된 시험 제출 원본 BSON/JSON 데이터
- vocabulary_exam_result_detailed.json: 30문항 문항별 정답/해설/선택답안 상세 리포트
